ROUTETRACK — PO AMD DEFAULT + CRF AUTO-FILL + DUPLICATE FIX

FILES INCLUDED
- src/lib/workflow.ts
- src/components/DocumentForm.tsx
- src/components/AppShell.tsx

CHANGES

1. PO DEFAULT ROUTE
- New PO records now default to:
  AMD — Receiving Department
- Default purpose:
  Product receiving / AMD acknowledgment
- The PO routing template now routes to AMD instead of Supplier / Vendor.

2. COPY CRF DETAILS INTO PO
- When the PO number exactly matches an existing CRF number, RouteTrack
  automatically copies:
  * Organization
  * Requesting department
  * Purchasing employee / requisitioner
  * Supplier
  * Amount
  * Description / items
- The PO form also includes a "Related CRF / copy details" selector.
- This selector allows copying details when the PO number and CRF number
  are different.
- PO-specific fields are not overwritten:
  * PO number
  * Date forwarded to supplier
  * Payment terms
  * AMD destination

3. FALSE DUPLICATE WARNING FIX
- Duplicate checking now uses:
  Document type + Document number
- CRF 1001 and PO 1001 are allowed.
- PO 1001 and another PO 1001 are blocked.
- The duplicate warning is temporarily suppressed during the active save
  request so the newly saved record does not warn against itself.
- Dashboard duplicate alerts use the same corrected rule.

4. CRF / PO STATUS WORDING
- New CRF and PO records remain In Transit after logging.
- They are marked Completed after acknowledgment.
- No Route next step is required.

HOW TO APPLY

1. Extract this ZIP.
2. Copy the included "src" folder.
3. Paste it into the root of your existing RouteTrack project.
4. Choose "Replace the files in the destination."

Then run:

npm run build

When successful:

git add src/lib/workflow.ts src/components/DocumentForm.tsx src/components/AppShell.tsx
git commit -m "Improve PO and CRF document entry"
git push origin main

Wait for the existing Vercel deployment to become Ready.
